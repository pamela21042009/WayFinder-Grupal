# WayFinder

Aplicación desarrollada con **Angular** e **Ionic**.

## Requisitos

- [Node.js](https://nodejs.org/) (versión compatible con la versión de Angular del proyecto).
- npm, incluido con Node.js.

## Instalación

Clona el repositorio y entra en la carpeta del proyecto:

```bash
git clone <URL_DEL_REPOSITORIO>
cd WayFinder-Grupal
```

Instala las dependencias:

```bash
npm install
```

## Desarrollo

Inicia el servidor de desarrollo de Ionic:

```bash
npx ionic serve
```

La aplicación se abrirá en el navegador. El servidor normalmente recarga la página cuando detecta cambios en el código.

## Compilación

Para generar una compilación de producción:

```bash
npx ionic build
```

Los archivos generados quedan en la carpeta de salida configurada por Angular.

## Tecnologías

- Angular
- Ionic
- TypeScript
